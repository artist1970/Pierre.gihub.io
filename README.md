# Pierre · Linguistics and Foreign Languages

This is Pierre's public educational landing page and local introductory linguistics chatbot.

- Public files: `index.html`, `pierre-conversation-v1.js`, `knowledge/public-qa.v1.json`
- Canonical identity: [PierreCore](https://github.com/artist1970/CORE/tree/main/PierreCore)
- Existing personal Code Capsule: [Pierre-language-data.html](https://github.com/artist1970/creative-spark.github.io/blob/main/Pierre-language-data.html)

## Naming / deployment
The repository's literal name is **`Pierre.gihub.io`** (not `Pierre.github.io`). Keep the existing name until a separately authorized repository rename is desired. A normal GitHub Pages project URL, if Pages is enabled, would be `https://artist1970.github.io/Pierre.gihub.io/`. Do not assume Pages deployment was enabled or verified by this commit.

## Behavior and limitations
The public chatbot uses a small read-only editorial knowledge file and browser-local deterministic routing. It is not a hosted generative AI model and does not store or send messages to a server. Optional reply speech relies on browser support and installed voices. No Code Capsule storage, keys, or private records are loaded.

## Safe Code Capsule sync contract
`Pierre-language-data.html` is an existing Creative Spark browser-local Mini Cloud workspace. Its localStorage is not shared with this origin. Future import requires explicit user export, schema validation, private-data exclusion, linguistic review, versioned approval, content deduplication and a reversible publication receipt. Do not overwrite its `cloudFS` storage or automatically publish drafts.
